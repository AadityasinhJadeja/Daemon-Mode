# Daemon Mode Fonts

These fonts are packaged locally so the dashboard and extension popup keep the
same visual identity without relying on a remote font CDN.

- Atkinson Hyperlegible: primary UI voice for headings, body text, capture
  titles, and buttons.
- Commit Mono: metadata, URLs, timestamps, stats, labels, snippets, and other
  data-like text.
- Literata Italic: the special daily brief / memory pulse sentence only.

Source files were downloaded from Fontsource packages for the respective
open-source fonts.
