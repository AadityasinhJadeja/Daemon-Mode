Before you start

Daemon can access the URL, page title, capture time, and readable page text on allowed sites. It saves them to local SQLite on this Mac so connected agents can retrieve cited evidence without changing your memory.

Protection and your blocks are checked before text is read. There is no Daemon account, analytics, or cloud sync. Chrome profiles enabled under the same macOS user share this local vault.
