Installation and recovery

Support.

Daemon Mode currently supports Google Chrome on macOS. The extension, companion local service, and MCP connection are separate parts of one local system.

Install the two local components

1. Companion local service

When public GitHub access opens, clone the repository and run the installer from its checkout:

git clone https://github.com/AadityasinhJadeja/Daemon-Mode.git
cd Daemon-Mode
./tools/install-local-service-launch-agent.sh

This installs and starts the companion service for your macOS user. It does not delete or replace an existing memory vault.

No window needs to stay open

The installer registers a per-user macOS LaunchAgent. The service starts after you log in, returns after a normal reboot once you log in again, and is restarted by macOS if the process exits unexpectedly. The dashboard is only a view into the service; closing its tab does not stop capture.

2. Chrome extension

During the technical preview, open chrome://extensions, turn on Developer mode, choose Load unpacked, and select this checkout's extension/ folder. Chrome will show its normal Developer mode warning. The official Store URL will replace this source-install step only after publication.

The extension is not the service

Installing only the extension does not create or host the memory vault. Chrome captures allowed pages; the companion service stores and retrieves them.

If the service is off

The background service does not run before login or while your macOS user is logged out. After login, the extension should reconnect without a dashboard or terminal window.

  1. Open the Daemon extension and confirm it reports that the companion service is unavailable.
  2. From the repository checkout, run the installer again. The managed installer is idempotent: it verifies the managed files, reloads an unloaded service, and preserves the memory vault.
  3. Confirm the loopback health endpoint responds:
curl --fail --silent --show-error http://127.0.0.1:4317/health

If the service still does not start, save the error text only. Do not attach your database or real captured content to a public request.

Connect an MCP client

The setup helper prints machine-correct configuration without changing anything by default:

python3 tools/setup-agent-harness.py

When ready, explicitly connect one verified client:

python3 tools/setup-agent-harness.py --apply codex --scope user

Replace codex with claude-code, cursor, or claude-desktop. The helper backs up existing configuration, preserves unrelated settings, and refuses malformed or conflicting files.

ChatGPT is not configured by this local helper. Its integration path is remote MCP/apps/connectors and would require a future bridge that preserves Daemon's non-destructive and protection boundaries.

Update safely

After updating a checkout, run the local service installer again. The managed-runtime workflow verifies the new release, preserves the database, activates it atomically, and restores the prior runtime if startup fails.

./tools/install-local-service-launch-agent.sh

During the technical preview, return to chrome://extensions and reload Daemon after updating the checkout. The official Store will handle extension updates only after that listing exists.

Uninstall without accidental data loss

Stop the background service with:

./tools/uninstall-local-service-launch-agent.sh

This preserves the managed runtime and SQLite memory by design. Removing the Chrome extension stops future capture but also does not delete the separate SQLite vault. Use the human-owned dashboard controls to export or clear memory before deleting files manually.

Ask for help safely

Never post private browsing material

Do not include real browsing text, URLs, databases, credentials, API keys, screenshots containing private pages, or local configuration files in a public support request.

After public launch, use GitHub Issues with synthetic details for installation or product problems. For a possible vulnerability, follow the Security reporting guidance instead of using public support.
