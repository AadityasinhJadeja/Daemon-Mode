Local agent memory · Chrome on macOS

Private memory for AI agents.

Daemon saves allowed pages to an owner-controlled SQLite file on your Mac, then gives connected agents citation-backed evidence through non-destructive MCP tools.

Why agent memory matters

Your agents stop starting from zero.

Daemon turns allowed reading into reusable evidence, then brings it back where your agents already work.

01 · Remember

Research becomes reusable context.

Allowed pages are saved locally without asking you to tag, file, or summarize them.

Example agent request“Which tools did I compare for this project?”
02 · Retrieve

Decisions return with evidence.

Local search gives connected agents the page, date, and citation behind what you previously read.

Example agent request“What evidence led me to this approach?”
03 · Cite

Unsupported memory stays unsupported.

Agents receive evidence with citations but cannot change the vault. No evidence means no invented answer.

Example agent request“Find the source behind that detail.”
